  <h2 align="center"><img src="vr/salas/imagens/icone.png" style="margin-bottom:-10px" width="45"> Apple curve fractals with polyhedra</h2>
The apple fractal curve is defined by seven equal-sized segments generated in each iteration. The segments of a given iteration form a curve that is symmetrical with respect to the perpendicular bisector of the generating segment from the previous iteration.
<center><img src="ar/0A.png" style="max-width: 50%;" alt=" Apple curve fractal"></center>
<br>This work shows apple fractal curve with polyhedra, modeled for visualization in Virtual Reality.

<h4>1. Tetrahedron</h4>
<a href="vr/curve1.htm" target="_blank" title="3D model" class="fotoA"><img src="ar/1A.png" class="foto" alt="Tetrahedron Apple curve fractal"></a>
 <br>Applying the construction principle of the apple curve fractal with the tetrahedron, we obtain an tetrahedron apple curve fractal. In the first order of construction of the fractal, we construct seven new tetrahedra corresponding to one original polyhedron. In this example, we have solid representations in orders from 0 to 3.
